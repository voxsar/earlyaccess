🛍️ Unified Wishlist Component

Dual-mode wishlist component - Regular Button + Floating Button with Popup

🔄 Display Modes

📱 Regular Button Mode

Perfect for product pages - adds products to wishlist with customizable button styles

🌐 Floating Button Mode

Site-wide floating button with full wishlist popup interface for viewing and managing items

✨ Key Features

📍 Configurable Position

Position the button on left/right side with custom offsets for perfect placement

🎨 Custom Styling

Fully customizable colors, text, and hover effects to match your brand

📱 Responsive Design

Adapts beautifully to mobile devices with optimized touch interactions

🛒 Smart Actions

Individual and bulk actions for adding to cart and managing wishlist items

⚙️ Configuration Options

Position Settings

Horizontal Position: Left | Right
Vertical Position: Top | Center | Bottom
Horizontal Offset: 0-100px
Vertical Offset: 0-200px

Style Settings

Button Text: Custom label
Background Color: Any hex color
Text Color: Any hex color
Hover Color: Any hex color

🔧 Popup Features

📋 Complete Product Info

Displays:

  • Product name with clickable link
  • Added date in DD MMM, YYYY format
  • Product image with lazy loading
  • Formatted price with currency
  • Individual Add to Cart and Remove buttons

⚡ Bulk Actions

Bottom toolbar includes:

  • Add All to Cart: Adds all available products to cart
  • Remove All: Clears entire wishlist with confirmation

💻 Technical Implementation

Files Created

Unified Template: wishlist-unified.liquid
Unified CSS: wishlist-unified.css
Unified JavaScript: wishlist-unified.js
Configuration: shopify.extension.toml
🚀 Ready to Deploy! The unified wishlist component is configured as a single theme extension with dual functionality. Merchants can add it to any section and choose between Regular Button mode (for product pages) or Floating Button mode (site-wide with popup).
